# Contact Book – MERN Stack

## Overview
Contact Book is a full-stack web application developed using the MERN stack. It provides an interface to manage contact information, including names, email addresses, and phone numbers.

The frontend is built with React, while the backend uses Node.js and Express.js to handle API requests. MongoDB is used to store contact records, with Mongoose managing database operations.

## Features
- Add new contacts with name, email, and phone number.
- View the list of saved contacts.
- Store and retrieve contact information from MongoDB.
- Edit and delete contacts
- Communicate between the frontend and backend through REST API endpoints.
- Use a responsive and interactive React interface.

## Technologies Used
- **MongoDB** – NoSQL database for storing contact details.
- **Express.js** – Backend framework for building REST APIs.
- **React.js** – Frontend library for building the user interface.
- **Node.js** – JavaScript runtime for the backend.
- **Mongoose** – Object Data Modeling (ODM) for MongoDB.
- **JavaScript** – Application logic.
- **HTML5 and CSS3 – Structure and styling.
- **Git and GitHub** – Version control and project hosting.

## Project Structure
- `Backend/` – Express server, database connection, contact model, and API routes.
- `frontendclient/` – React frontend application.

## Learning Objectives
This project demonstrates simple full-stack development fundamentals, including React components and state management, REST API integration, Express middleware, MongoDB database connectivity, and Git-based version control.
